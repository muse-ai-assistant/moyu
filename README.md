# 🐟 摸鱼办 · Moyu

带薪摸鱼，下班倒计时。设置下班时间，大字实时倒计时，附赠摸鱼语录。

**在线体验 → https://muse-ai-assistant.github.io/moyu/**

## 功能

- ⏰ 设置下班时间（默认 18:00，localStorage 记住），精确到秒的大字倒计时
- 💬 20 条摸鱼语录，每 30 秒换一条
- 📊 今日已摸鱼时长统计（页面打开累计计时）
- 🎉 周五专属"周五快乐"彩蛋横幅

## 技术

纯 HTML + CSS + JS 单文件应用，零依赖，PWA 可安装离线使用。

## 隐私

下班时间只保存在你的浏览器本地，不上传服务器。
